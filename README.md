Iterated Prisoner’s Dilemma (IPD) Strategy Analysis & Prediction
📌 Project Overview

This project focuses on simulating the Iterated Prisoner’s Dilemma (IPD) using the Axelrod library and analyzing how different strategies perform under varying conditions such as noise, probability of ending, number of turns, and repetitions.

The goal is to:

Simulate tournaments between multiple IPD strategies

Compute performance metrics like average payoff

Identify the winning strategy

Prepare a clean dataset that can later be used for machine learning prediction
